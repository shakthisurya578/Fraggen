# Dataset V4 ablation study

_Generated by `scripts/analyze_ablations.py` from the evaluation reports in this folder. Do not edit by hand; re-run the script._

> **Scope.** `val.npz` and `test.npz` are *held-out files* drawn from the same source pool as `train.npz`. These are **not** cross-corpus numbers. The project's cross-corpus result (train FFT-75 → test GovDocs1) is in `../cross_corpus_fft75_govdocs1/` and `docs/thesis/FINDINGS.md`.

## Setup

- Data: `data/processed_v4`: 61,940 train, 13,111 val and 13,754 test fragments, 4096 B, 9 classes
- Training: `configs/real.yaml`, 6 epochs, every training fragment (`--limit 0`), seeds 1337, 1338, 1339; best epoch kept by accuracy on a 10% split of `train.npz`
- Driver: `python scripts/run_ablations.py` (the defaults reproduce this protocol)

### The cumulative ladder

| config | adds | `src.training.train` flags |
|---|---|---|
| A_plain | (none: plain byte-CNN) | `--no-aug --no-aux --no-adv --no-contrastive` |
| B_aug | fragment augmentation | `--no-aux --no-adv --no-contrastive` |
| C_aux | entropy auxiliary features | `--no-adv --no-contrastive` |
| D_adv | entropy adversary (gradient reversal) | `--no-contrastive` |
| E_full | contrastive pre-training | `(all mechanisms on)` |

The ladder is cumulative: each rung keeps everything before it. Contrastive pre-training therefore enters at **E_full**, and its marginal effect is E_full − D_adv (see the consecutive-rung table). In this code base the third rung is `C_aux` (entropy auxiliary features). There is no separate `C_contrastive` configuration, and the ladder was kept unchanged so every V4 number stays comparable with the earlier ablation matrices.

## What the statistics support

- **B_aug** (fragment augmentation): test accuracy 0.8958 ± 0.0032 vs 0.8938 ± 0.0036; Δ = +0.0019 (95% CI -0.0094 to +0.0132, paired p = 0.543, Holm 1.000); Δ macro-F1 = -0.0006 (paired p = 0.883). Fragment-level McNemar: significant in 2/3 seeds; B_aug fixes more fragments than it breaks in 2/3 seeds.
- **C_aux** (entropy auxiliary features): test accuracy 0.8938 ± 0.0086 vs 0.8938 ± 0.0036; Δ = -0.0001 (95% CI -0.0219 to +0.0217, paired p = 0.990, Holm 1.000); Δ macro-F1 = -0.0011 (paired p = 0.854). Fragment-level McNemar: significant in 2/3 seeds; C_aux fixes more fragments than it breaks in 2/3 seeds.
- **D_adv** (entropy adversary (gradient reversal)): test accuracy 0.8603 ± 0.0152 vs 0.8938 ± 0.0036; Δ = -0.0336 (95% CI -0.0765 to +0.0094, paired p = 0.078, Holm 0.313); Δ macro-F1 = -0.0354 (paired p = 0.047). Fragment-level McNemar: significant in 3/3 seeds; D_adv fixes more fragments than it breaks in 0/3 seeds.
- **E_full** (contrastive pre-training): test accuracy 0.8760 ± 0.0159 vs 0.8938 ± 0.0036; Δ = -0.0179 (95% CI -0.0663 to +0.0306, paired p = 0.253, Holm 0.759); Δ macro-F1 = -0.0206 (paired p = 0.210). Fragment-level McNemar: significant in 2/3 seeds; E_full fixes more fragments than it breaks in 1/3 seeds.

No mechanism changes V4 test accuracy by an amount distinguishable from seed-to-seed variation at n = 3 seeds (seed-paired t-test, Holm-corrected).
With 3 seeds the paired t-test has 2 degrees of freedom, so only large, consistent differences can reach significance. A non-significant result means *no detectable effect at this sample size*, not *no effect*. McNemar asks a different, narrower question: whether two specific trained models make different mistakes on this fixed test set. It says nothing about the expected effect of the training recipe.
